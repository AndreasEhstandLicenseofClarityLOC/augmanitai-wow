# Security Policy

## Scope
This repository is a static content site (single-file HTML knowledge-graph
artifact with hand-written vanilla JavaScript and no external dependencies,
plus discovery/metadata files). There is no server-side component, no build
pipeline, no user accounts, and no data collection.

## Reporting a vulnerability
If you discover a security issue (for example: a content-injection vector in the
static page, a metadata/identifier inconsistency, or a privacy concern), please
report it responsibly:

- Email: **ehstand.schule@gmail.com**
- Subject line: `SECURITY — augmanitai-wow`

Please include:
- a description of the issue and where it occurs,
- steps to reproduce (if applicable),
- the affected file(s) or URL(s).

## Response
- Acknowledgement target: within 7 days.
- Please allow reasonable time for a fix before any public disclosure
  (coordinated / responsible disclosure).

## Out of scope
- Denial-of-service against the GitHub Pages host.
- Issues in third-party platforms (GitHub, Zenodo, ORCID, Wikidata) themselves.

Thank you for helping keep this project safe.
